       - Export getPrivyClient(): PrivyClient
       - Constructor: new PrivyClient(process.env.NEXT_PUBLIC_PRIVY_APP_ID!, process.env.PRIVY_APP_SECRET!)
         NOTE: Check @privy-io/node types after install. Constructor may take positional args (appId, appSecret) or an options object. Inspect the type definition and use the correct signature.
       - Export async function verifyAuth(request: NextRequest): Promise<{ userId: string }>
         - Reads 'privy-token' from request cookies (NOT from next/headers cookies() -- that is for server components, not route handlers)
         - If no token, throw Error('Not authenticated')
         - Calls getPrivyClient().verifyAuthToken(token)

       - Export config.matcher: ['/dashboard/:path*']
       - Do NOT do full token verification in middleware (Edge runtime limitation, security note from research)

       - Keep everything else unchanged
       - Pages that use cookies()/headers() automatically become dynamic in Next.js 15
