   ```typescript
   export interface CreatorCardData {
     handle: string;

     avatarUrl: string | null;
     priceUsd: number | null;
     holderCount: number | null;
     tokenMint: string;
   }
   ```


3. **`extractCardData(item: BagsTokenLeaderBoardItem): CreatorCardData`** — Extracts card-friendly data from a raw SDK item. Uses optional chaining for null safety:
   - `handle`: `item.creators?.[0]?.twitterUsername ?? item.creators?.[0]?.username ?? "unknown"`
   - `displayName`: `item.tokenInfo?.name ?? item.creators?.[0]?.username ?? "Unknown"`

   - `priceUsd`: `item.tokenLatestPrice?.priceUSD ?? null`
   - `holderCount`: `item.tokenInfo?.holderCount ?? null`
   - `tokenMint`: `item.token`

4. **`getCreatorsForGrid(): Promise<CreatorCardData[]>`** — Fetches and transforms creator data:
   - Check cache with key `"landing:creators"`
   - If cached, return cached `CreatorCardData[]`
   - Call `getBagsSDK().state.getTopTokensByLifetimeFees()`
   - Map results through `extractCardData()`
   - Cache the transformed array with 30_000ms TTL
   - On error, `console.error` and return `[]`

Follow the exact same mock pattern as `tests/api/creators.test.ts` — mock `@/lib/bags` and `@/lib/cache` with `vi.mock()` before imports. Use `vi.fn()` cast pattern for type-safe mock access.
